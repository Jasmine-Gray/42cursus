# DB設計

実装の正本は `backend/priv/repo/migrations/`。IDと状態値はAPI契約の語彙を使う。

| テーブル | 保存内容 | 主な画面 |
|---|---|---|
| `users` | アカウント、表示名、アバター、自己紹介、在席状態 | ログイン、ホーム、プロフィール |
| `sessions` | Bearer tokenのハッシュと有効期限 | 認証 |
| `friendships` | 申請者、受信者、申請状態 | フレンド |
| `rooms` | 招待コード、部屋設定、ホスト、状態 | ホーム、招待、ロビー |
| `room_members` | プレイヤー／観戦者、準備、接続状態 | ロビー |
| `word_pairs` | ジャンル、近さ、多数派と少数派のお題 | 部屋設定、ゲーム開始 |
| `games` | フェーズのスナップショットと確定結果 | ゲーム中、対戦履歴 |
| `game_players` | 参加種別、役職、割り当てたお題 | お題確認、結果、対戦履歴 |
| `chat_messages` | 公開チャット履歴 | 議論、再接続 |
| `votes` | 投票者と投票先 | 投票、結果 |

戦績と得票数は`games`、`game_players`、`votes`から集計する。タイマーなどの進行中状態はGameServerを正本とし、DBには復旧と履歴に必要な値だけ保存する。

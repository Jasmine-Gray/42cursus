# Extra: お題グループと逆転モード

`d/extra-game-modes` で開発し、`develop` に統合済み。

- 難易度を廃止し、部屋ではジャンルと逆転モードを指定する。
- お題は関連する2語以上のグループで保存する。グループを抽選してから異なる2語を選び、多数派・少数派も毎回無作為に割り当てる。
- 同じ部屋で候補が複数ある場合、直前のゲームのグループを除外する。
- 現行のお題は全8ジャンル各12組、計96組。食べ物・場所・遊び・暮らしなど幅広く扱い、商品名は使わない。
- 新しい部屋では全8ジャンルを初期選択する。[全お題と選定基準](word-catalog.md)。
- 逆転モードは部屋ごとに既定OFF。ウルフが単独最多票になった場合のみ、30秒・1回の回答へ進む。
- 入力中の文字は参加者・観戦者へ公開。プレイヤーへの正解のお題の公開は結果確定後。観戦者は専用一覧で全員のお題・役職を確認できる。
- 正解でウルフ勝利、不正解・時間切れで市民勝利。未確定の下書きは正解でも時間切れで失敗。
- 全半角、空白、英字の大小、ひらがな・カタカナを正規化して判定する。漢字の読み替えや別名・類義語は自動判定しない。
- 回答中の切断ではゲームを一時停止し、再接続時は残り時間と下書きを復元する。

## 起動

```sh
make up
```

アプリ: https://localhost:8443 。`develop` で起動し、部屋作成時に逆転モードをONにする。
初回起動時にDBマイグレーションとお題のシードが実行される。

## データ

`backend/priv/word-groups.json`が追加お題の保存元。`words`は重複のない2語以上で、配列順に陣営の意味はない。
現行リストから外したお題は、`WordWolf.DevSeeds.sync_word_groups/0`でDBの`active`をfalseにする。DBの行・過去のゲーム・配布済みのお題は削除しない。`"active": false`でリスト内に残すこともできる。
お題だけを反映する場合は`mix run -e 'WordWolf.DevSeeds.sync_word_groups()'`を使う（部屋やユーザーを再シードしない）。
既存のゲーム・各プレイヤーの配布済みお題を保持して`word_pairs`から`word_groups`へ移行する。
シードを繰り返してもIDで更新するため増殖しない。逆転の確定回答・成否・時間切れはgamesにも保存する。

契約は`_docs/spec/api/openapi.yaml`と`_docs/spec/api/asyncapi.yaml`。
`COMEBACK`フェーズと`comeback.draft`・`comeback.submit`・`comeback.updated`を追加。

## 観戦者のお題一覧と部屋別の時間設定

観戦者は議論・投票・逆転回答中に「みんなのお題」で各プレイヤーの名前・お題・役職を確認できる。取得は観戦者専用の `GET /games/{gameId}/spectator-assignments`。プレイヤー・未参加者・退出済み観戦者には返さず、公開Channelにも載せない。

部屋作成時と待機中のロビーで、ホストが議論時間（30〜900秒、既定300秒）と投票時間（10〜180秒、既定30秒）を指定できる。保存後は全員に表示を配信し、次のゲームで使用する。開始後の設定変更は拒否する。既存の部屋の時間列を使うため追加のDB移行は不要で、次回の `make` の再ビルドで反映される。

## 募集中の部屋の操作

設定変更はロビーの「ゲーム設定」表に集約する。ホストが表の中でジャンル・逆転モード・議論時間・投票時間を選び、「設定を保存」で参加者へ同期する。ホームには設定変更ボタンを表示しない。ジャンルは1つ以上必要で、時間は候補からの選択または秒数の直接指定ができる。

ホストはロビーのプレイヤー・観戦者のキックアイコンから対象名を確認して退出させられる。自分自身・ホスト以外の操作・開始後の操作は拒否する。対象者の部屋チャンネルを閉じ、退出理由とホームへの導線を表示する。本人用チャンネルにも部屋名付きの通知を送り、ロビー以外でも受信できる。通知は閉じるまで画面を移っても残る。参加禁止にはしないため、招待から再参加は可能。

ゲームは3〜8人で、全員が準備完了・接続中なら開始できる。次回の `make` でマイグレーションを実行し、既存の部屋も最低3人へ更新する。

ゲーム中に複数人が切断した場合は、切断中の全員の名前と人数を表示する。一部だけ戻ってもゲームとタイマーを停止したままにし、全員が最初の切断から20秒以内に戻ったときだけ再開する。追加の切断や一部の再接続では期限を延長せず、全員が戻らなければ勝敗なしで中止する。

招待URLはプレイヤー用／観戦者用を切り替え、URLとコピーアイコンを一行で表示する。ロビーとフレンド一覧では、招待済みの相手にも「再招待」で通知を送り直せる。未承認の招待は同じIDを再利用するため、受信した招待一覧には重複しない。

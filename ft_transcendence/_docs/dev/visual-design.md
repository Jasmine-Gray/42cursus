# ワードウルフの画面デザイン

ヴィクトリア朝ロンドンの背景画像に、暗い操作パネル、真鍮色のボタン、重ねたお題カード、肖像カード形式のプレイヤー一覧を配置する。

Blenderのモデル、生成スクリプト、Three.js描画は撤去。背景は `public/scenes/victorian-alley.png`。霧の動きはCSSで実装し、表示時の短い動きのみとし、非表示タブ・動作軽減設定に対応する。背景操作のツールバーとゲーム名のタイトル表記は撤去した。

「お題を確認・会話で探る・ウルフに投票」の3ステップ説明は撤去した。

`frontend` の `/login`、`/register`、`/lobby` で確認できる。未接続画面は `frontend/src/mocks/` のローカルモックを使用。対戦相手・タイマー・結果はサンプルで、サーバー保存や実際の招待は行わない。

背景の画像はimagegenで制作した素材。画像とUIは `_docs/mock` と `frontend` に同じものを配置する。

背景は元画像の左手前の炎を68×91px相当で切り出し、境界を固定した16コマのラスターストリップをブラウザで生成して80msずつ切り替える。炎の図形や光の塊を重ねない。雨・雲・霧は別レイヤーで、動作軽減設定と非表示状態では停止する。

フォームの検証メッセージには初期状態から余白を確保。アバター候補は80px固定。パネルと肖像カードは暗い茶色と真鍮の縁取りで統一する。

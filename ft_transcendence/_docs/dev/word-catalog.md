# お題カタログ

現行リストは全6ジャンル各12組、計72組。保存元は `backend/priv/word-groups.json`。
食べ物・外出・遊び・暮らし・学校や仕事・エンタメまで幅広く扱う。

## 選定基準

- 商品名・ブランド名・作品名を使わず、説明なしで意味が通じる言葉にする。
- 両方に通じる話題があり、用途・体験・好み・習慣の違いを話すうちにずれが出る組を選ぶ。
- 「いつ？」「誰と？」「どこで？」「好き？」「いくらかける？」など、複数の角度で話せる組を選ぶ。
- 同義語の言い換えだけ、専門知識の違いだけで決まる組を避ける。
- 1組2語で相性を確認する。単語の配列順は多数派・少数派を指定しない。
- 各ジャンルの組数を揃え、全ジャンルで遊ぶときに特定のジャンルへ偏らせない。

新規部屋は全6ジャンルを初期選択。遊びたいジャンルだけに絞ることもできる。

## 会話が分かれる例

- **水族館／プラネタリウム**：「誰と行く？」「暗い方がいい？」「眠くなる？」。静かに眺める話から、歩き回るか座って見るかの違いが出る。
- **プリン／茶碗蒸し**：「冷たいのも好き？」「家で作る？」「いつ食べる？」。卵や食感は共通でも、食事の中での位置づけがずれる。
- **キャンプ／車中泊**：「どこで寝る？」「何を持っていく？」「雨でもできる？」。屋外の宿泊から準備や快適さの違いが出る。
- **目覚まし時計／キッチンタイマー**：「何個使う？」「鳴っても放置する？」「スマホで十分？」。時間を知らせる道具でも使う場面がずれる。
- **カンニング／丸写し**：「一度だけなら？」「友達に頼まれたら？」「どこからアウト？」。答えを借りる話から、場面や罪悪感の違いが出る。
- **ガチャガチャ／福袋**：「欲しいものが出なかったら？」「いくらまで使う？」「人に譲る？」。中身が分からない買い物でも、買う場所や期待がずれる。

外した組は現行JSONから削除し、既存DBでは出題を停止して履歴用に保持する。残す組のIDと単語は変更しない。

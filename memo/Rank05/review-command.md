### 1. サーバーの起動と全インターフェースでのリッスン
要件: The server starts, and listens on all network interfaces on the port given from the command line.
（サーバーが起動し、コマンドラインから与えられたポートで、すべてのネットワークインターフェースからの接続を待ち受けること。）

【確認方法】

ターミナルでサーバーを起動します： ./ircserv 6667 password

別のターミナルを開き、以下のコマンドを実行して、ポート 6667 がすべてのインターフェース（0.0.0.0 または *）でリッスン状態（LISTEN）になっていることをレビュアーに見せます。

Bash
```
lsof -i :6667
# または
netstat -an | grep 6667
```
(※コード内の address.sin_addr.s_addr = htonl(INADDR_ANY); が正しく機能していれば、ここは問題なくクリアできます！)

テスト2: クライアントの予期せぬ強制終了
目的: クライアントが /quit コマンドなどで正常に切断するのではなく、突然プロセスがキルされたり通信が切れたりした場合でも、サーバーが落ちないか確認します。

【テスト手順】

[ターミナル2 (Irssi)] Irssiでサーバーに接続し、ログインした状態にします。

[ターミナル2 (Irssi)] ここでIrssiを強制終了させます。

* 方法A: ターミナルのタブやウィンドウの「×」ボタンを押して無理やり閉じる。

* 方法B: 別のターミナルから kill -9 <IrssiのプロセスID> を実行する。

[ターミナル1 (サーバー)] サーバーがクラッシュせずに動き続けていることを確認します（ログに「Client disconnected」などと出れば完璧です）。

[ターミナル3 (別のIrssi)] 新しくIrssiを起動し、サーバーに接続できるか確認します。

【確認ポイント】

誰かが突然いなくなっても、サーバーのプロセスが終了（セグフォなど）せず、新しい人が問題なく接続できること。

```
プロセスID調べ方
- pgrep irssi
- ps aux | grep irssi
```

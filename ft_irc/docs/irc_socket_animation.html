IRC server は socket programming の上に乗っている

IRC の `PASS`、`NICK`、`USER`、`PRIVMSG` は TCP に流れる文字列です。 socket programming は、その文字列を運ぶ接続、fd、`recv()`、`send()`、`poll()` を扱います。

socket() -> bind() -> listen() -> poll() -> accept() -> recv() -> IRC parse / dispatch -> send() -> close()
listening socket: 新規接続を待つ fd
client socket: accept 後の会話用 fd
client bytes: IRC command text
server reply: numeric / message

読み込み recv() と 書き込み send()

TCP は バイトの流れ（stream）です。recv() 1 回が IRC コマンド 1 個とは限りません。 だから client ごとに 入力バッファに溜め、\r\n が来た行だけ切り出して処理します。 返信は 出力バッファに積み、send() で書き出します（一度に全部送れるとは限らない）。

← READ
recv() → 入力バッファ → 行に分割
→ WRITE
出力バッファ → send()

READ — client から読む

recv(fd, buf, 4096, 0)
fd 7 client socket
送ってくる側
inputBuffer_（client ごと） empty

WRITE — client へ書く

send(fd, buf, size, 0)
fd 7 client socket
受け取る側
outputBuffers_[fd] empty

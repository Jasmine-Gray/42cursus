poll() ループと pollfd の流れ

ft_irc は fork も thread も使わず、1 つの process が pollfds_ 配列で全 socket を監視します。 events（見たいもの）を毎周セットし、poll() が revents（実際に起きたこと）を書き込み、 その値で accept / recv / send / close に枝分かれします。実コードは srcs/server/Server.cpp の run() です。

updatePollEvents() -> poll() で待つ -> revents を読む -> accept / recv / send / close -> loop へ戻る
